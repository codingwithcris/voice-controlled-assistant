# Voice-Controlled Assistant
A voice-controlled assistant built with Python that helps automate everyday tasks through voice commands.

## Planned Features
**Email Management:** Check emails.
**Google Calendar Integration:** Schedule calendar events.
**Website Automation:** Automate browser interactions.

## Technologies
Playwright — Browser automation
pyttsx3 — Text-to-speech functionality
SpeechRecognition — Speech recognition from audio input
PyAudio — Audio input and microphone access
dotenvx — Environment variable and secrets management
uv — package and project management
